Dual-Engine Data Structure Memory Anatomy

BST Memory Node Structure (bst.h)

typedef struct Book {
    int id;
    char title[100];
    char author[100];
    int dueDate;        // YYYYMMDD
    bool isReturned;    // Status Flag
    struct Book *left;  // Left Child
    struct Book *right; // Right Child
} Book;

• Owns single malloc() memory allocation.
• Sorted case-insensitively by title string.
• O(log n) avg search, insert, and delete.

Min-Heap Dynamic Array Structure (heap.h)

typedef struct MinHeap {
    Book** books;      // Dynamic Array of Pointers
    int size;          // Current Element Count
    int capacity;      // Array Allocated Capacity
} MinHeap;

• Zero-copy pointers (Book* references).
• Ordered by integer due date (YYYYMMDD).
• Filters out books where isReturned == true.
